# Jane Street ASIC reverse-engineering puzzle

This repository contains the files supplied with Jane Street's ASIC puzzle and
a Windows-native pipeline for recovering, validating, analyzing, and simulating
the circuit from its GDS layout.

## Start here

- [WRITEUP.md](WRITEUP.md) tells the story of the reverse-engineering process,
  explains what the recovered circuit does, and includes the final result. It
  contains spoilers.
- [PIPELINE.md](PIPELINE.md) gives the setup and commands needed to reproduce
  each stage and describes the generated outputs.
- The [original Jane Street post](https://blog.janestreet.com/can-you-reverse-engineer-an-asic/)
  explains the puzzle and its rules.

## Repository layout

- `asic_re/` contains the Python extraction, Verilog export, graph analysis,
  simulation, solving, and diagnostic scripts.
- `tests/` contains the pytest checks and Icarus Verilog testbenches.
- `warmup/` contains the supplied warm-up design at several stages from RTL to
  final GDS.
- `puzzle.gds`, `example_inputs.vcd`, and `layout.png` are the supplied puzzle
  layout, example waveform, and annotated floorplan.
- `Makefile` provides the warm-up, replay, test, solve, analysis, and Easter-egg
  targets used by the pipeline.
- `artifacts/` is generated locally by the pipeline. It holds extracted
  netlists, structural Verilog, reports, simulations, and the solved bitmap.
- `third_party/sky130_fd_sc_hd/` is generated by the model downloader and holds
  only the SKY130 files required by the recovered designs.

The flow was developed for Windows using Git Bash, Python, KLayout, NetworkX,
Z3, pytest, `vcdvcd`, Make, and Icarus Verilog 12. See
[PIPELINE.md](PIPELINE.md) for environment setup and execution details.
